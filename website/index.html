Axero.js

Build real-time apps like breathing.

Zero-dependency fullstack framework. Native WebSocket on one port, fine-grained signals, no Virtual DOM.

Get Started GitHub
# install
$ npm install
 
# create app
$ axero create my-app
 
# run — HTTP + WS on one port
$ cd my-app && axero dev
→ http://localhost:3000
0

Zero Dependencies

Native Node.js HTTP + WebSocket. No ws, no socket.io, no bloat.

1

Real-Time First

HTTP and WebSocket share one port. No separate server, no CORS.

2

Fine-Grained Signals

Reactivity without Virtual DOM. Direct DOM updates, tiny bundle.

3

File-Based Routing

Drop a file in routes/. It's a route. Params with [id].

Start in seconds

No config, no boilerplate. One command to a running app.

# 1. Create a new app
$ axero create my-app
created my-app — cd my-app && axero dev
 
# 2. Run it
$ cd my-app && axero dev
axero app on http://localhost:3000
 
# 3. Open two tabs, send a message — real-time works.
